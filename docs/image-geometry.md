# Interactive crop frames

The crop icon, **C**, **Ctrl+T**, or **Image → Crop frame** opens a crop aperture. Drag corner/edge handles to trim, drag inside or grab its center **+** to move it freely on X and Y, or drag outside the existing selection to draw a new frame. Movement works at every crop size, including the full photo and a one-pixel selection. The thirds grid and dimmed margins show what will remain. Aspect choices are Free, Original, 1:1, 4:5, 3:2 and 16:9. Shift temporarily preserves the current proportions while dragging a free crop.

Cropping replaces the image resize tool. There is one crop tool in the toolbar and context bar. The resize mode, resize icon and dimensions dialog have been removed. Dragging handles changes the selection; it never changes the scale of the underlying photograph.

The round handle and **Frame** angle field rotate only the aperture. The photograph remains fixed and upright. Moving or rotating the frame never reduces its extents to fit the image. It can extend past any image edge; a checkerboard shows transparent regions without stretching edge pixels. PNG retains these regions and rotated-frame corners; JPEG composites transparency onto white. Shift snaps rotation to 15° steps. Image-menu rotation commands open a frame preview for review. A rotated aperture creates a clipped image within an axis-aligned bounding canvas. This is frame rotation, not image straightening.

**Arrow keys** nudge the frame by one native pixel; **Shift + arrows** move it by ten. **Shift-drag** locks movement to the initial dominant X or Y axis until Shift is released. Drag positions are calculated from the gesture origin, so moving out and back does not accumulate drift. Translation snaps to native pixels and keeps output dimensions stable, including when the selection extends wholly beyond the image. Handles can also extend the crop canvas past the photo; empty areas remain transparent and the photograph keeps its native scale.

Hold Space and drag to pan at any zoom, including Fit and zooms smaller than the workspace. There is no image-overflow clamp or snap-back. Crop mode temporarily folds away the preset gallery and retouch inspector, then restores them on exit; History and Layers remain accessible. The initial fitted crop view leaves space around the photo and handles. Hold a frame or handle drag at a canvas edge to keep scrolling in that direction without releasing the mouse. **0 / Fit** brings both the frame and photo into view, without moving the frame relative to the photo. The wheel / filmstrip controls zoom without modifying pixels.

**Apply / Enter** commits one undo step; **Cancel / Escape** discards the draft. Selecting another photo cancels an unfinished preview. **Reset frame** restores hidden crop margins. The source file is never overwritten. The existing 32,768-pixel dimension and 80-megapixel output limits still apply to extended canvases; navigation does not allocate a larger image.

During drags, only GPU geometry changes. An uncropped document reuses its sharp edited overview. Reopening a committed crop prepares its hidden margins and existing retouch on a cancellable worker once; pointer movement does not launch new renders. Native geometry is prepared only after Apply. Cropping copies source pixels and changes alpha along the aperture boundary; interior pixels are not rotated or resampled.

Stroke centers, clone sources, warp vectors, patch boundaries, layer masks and export crop positions are projected into cropped document coordinates. AI inference uses the source; generated maps and landmarks are aligned with the working document. Undo/redo, photo switching, recovery and saved workspaces retain geometry. Working images and lossless PNG exports use the same preparation path.

**Original size** export uses the cropped document dimensions; export presets can produce other output dimensions afterward. Session versions 1–4 retain their previous transforms and default to no crop. New saves use version 5 with frame geometry in current edits and both history branches. Existing saved image transforms remain supported for compatibility; new crop actions do not add image scaling or rotation.

## Verification

Tests exercise every crop entry point, absence of obsolete resize controls, raw egui pointer drags, full-size/tiny/rotated frame movement, arrow nudging, stable axis locking, drift-free return, aspect selection, stationary image UVs during frame rotation, Shift snapping, unrestricted Hand/Space-pan at Fit and small zooms, continuous edge scrolling, frame-and-photo Fit, panel restoration, one-step commit, cancellation, undo/redo, crop reset and margin reopening. Pixel checks cover unchanged crop interiors, all four transparent margins, fully outside frames, extended canvases, stable output dimensions, source preservation, compact/dense AI maps, saved geometry and PNG consistency. Inspect native desktop and compact screenshots before packaging. The beta remains unsigned, and a separate Windows PC or VM is still needed for clean-machine installer testing.
